UCanWorkFromHome.com — Version 13.6.2

WHAT CHANGED
- Added a new kindergarten mystery-box counting activity to Math Adventures K–3.
- Six colorful blank boxes can be selected in any order.
- Each newly selected box reveals the next number from 1 through 6.
- The browser voice says each number aloud.
- A short cheerful pulse highlights each reveal without continuous blinking.
- Every selected box stays brightly outlined and glowing, so the child can
  clearly see the growing group of one, two, three, and so on.
- Changed the selected-box highlight to a stronger blue-and-white glow.
- Voice playback now favors natural, premium or enhanced English voices and
  uses a calmer speaking pace.
- Completing all six boxes triggers a spoken celebration.
- “Mix the boxes” clears the activity and rearranges the boxes for another round.
- Added keyboard, touch, screen-reader and reduced-motion support.
